## 采集审核"待审(N)但列表为空" — 已修复 ✅
- **根因**: `reload()` 构建参数时 `resolution: resolutionFilter.value || undefined` 和 `search: search.value || undefined`
  - 值为空字符串时 `||` 返回 JS 的 `undefined`，`URLSearchParams` 把它序列化为字符串 `"undefined"` 传给后端
  - 后端 SQL 收到 `resolution='undefined'` → WHERE 条件不匹配 → 返回 0 条
- **修复**: 改为条件添加（`if (value) params.key = value`），空值时不传该字段
- **文件**: `web/src/views/IntakeReview.vue`

## 关于"采集审核是下载前还是下载后"
- 采集审核的候选文献**元数据已有**（标题、作者、摘要等），但 PDF **可能已下载也可能没下载**
- 看 `local_pdf_path` 和 `fetched_sha256` 字段：有值 = 已下载，空 = 仅元数据
- 审核通过后"晋升"才会成为正式 work 进入库

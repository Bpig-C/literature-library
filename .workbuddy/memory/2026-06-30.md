## Architecture Docs Sync (三模块关系)

### Question Answered
- **Topic Gate**: 前置输入源 + 成熟度管理器（不是后置分类器），为 Discovery 提供 topic_id + query_def
- **Discovery**: 受约束发现检索层，agent 回填 hits → 用户审核 accept → 通过 `accept_hit_to_intake()` 桥接到 intake

# 业务流程图维护入口

本目录维护“事情如何发生”，与 `docs/architecture` 的“系统由什么组成”分开。

## 文件

| 文件 | 范围 |
| --- | --- |
| [business-flows.md](business-flows.md) | 用户浏览器流程、agent CLI 流程、agent/API 自动化流程、跨模块协作流程 |

## 维护约定

- 流程图使用 SVG 图片引用，以兼容 VS Code 自带 Markdown Preview。
- 每条流程必须标出入口、关键状态写入点、产物位置和审核门禁。
- UI、CLI、API 三条链路如果共用同一业务能力，应画在同一节中，避免后续行为漂移。
- 长流程更新时，至少安排两轮审核：第一轮核对代码事实，第二轮核对图与文字是否互相矛盾。

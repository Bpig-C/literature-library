## 决策记录

1. **API 薄适配器模式**：直接复用 scripts 包函数，不在 API 层重写业务逻辑
2. **批量限制**：默认 limit=5，防止误触发全库重跑
3. **force 参数**：前端抽取按钮使用 force=true，允许重新抽取
4. **workflow bar**：采用线性布局，状态基于 DB 实时查询
5. **主题创建**：默认 seedling/active，符合成熟度模型

## 剩余风险

1. **同步执行**：元数据/分类抽取是同步调用，大 batch 可能较慢
2. **LLM 依赖**：抽取功能依赖 LLM 服务可用性
3. **无后台任务**：V1.1 不做完整后台任务队列系统

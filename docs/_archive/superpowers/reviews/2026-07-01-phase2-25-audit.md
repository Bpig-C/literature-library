### 代码质量评价

**架构设计**: ⭐⭐⭐⭐⭐
- `confirm` ref 统一管理弹窗状态（show/title/message/action 四字段）
- `showConfirm()` 辅助函数封装了弹窗触发模式，4 个批量操作代码高度一致
- 每个 batch 操作的 action 函数首行就是 `confirm.value.show = false`——**关弹窗优先**，避免重复点击

**API 使用正确性**: ⭐⭐⭐⭐⭐
- 8 个 API 全部是 api.js 里已封装的现有接口，无新增后端依赖
- `parseTrigger({ all_pending: true })` 参数格式与后端一致
- `getMetadataExtractions({ status: 'pending', per_page: 1 })` 只取 total 字段，不浪费带宽

**UI/UX 细节**: ⭐⭐⭐⭐☆
- disabled 语义正确（count=0 或 loading 时禁用）
- spinner 用纯 CSS 实现（@keyframes spin），无额外依赖
- stat-badge 有 `.has-items` 高亮态（accent 色 vs muted 色）
- stage-card hover 有 border-color 过渡

## 风险项

1. **中风险：`batch_accept_hits` 不过滤 title-only low-confidence hit**
   - 计划文档要求"title-only low-confidence hit 不被批量接受"
   - 实际实现不过滤，直接调用 `accept_hit_to_intake`
   - 建议：在 `batch_accept_hits` 中增加过滤逻辑
   - 影响：低质量候选可能进入 intake，但仍需人工审核

2. **低风险：canonical_url 去重可能过于简单**
   - `_canonicalize_url` 只做 scheme+host 小写化 + 去尾斜杠
   - 不处理 query params、fragment、path 大小写
   - 对于同一资源的不同 URL 变体可能不去重
   - 评估：V1.1 可接受，后续可增强

3. **低风险：agent 回填后 run 状态自动改为 succeeded**
   - `backfill_hits` 端点在 created > 0 时自动将 run 从 planned 改为 succeeded
   - 如果 agent 分批回填，第一批后 run 就变成 succeeded
   - 评估：功能正确，但语义上可考虑增加 "partially_backfilled" 状态

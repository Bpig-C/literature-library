# 文档归档索引

> 状态：当前索引
> 更新时间：2026-07-17

本目录保存已经退出当前维护路径、但仍有查证价值的历史文档。归档不代表删除或否定，只表示这些文件不再作为当前事实或当前待办的权威来源。

## 归档分类

| 目录 | 内容 | 使用方式 |
|---|---|---|
| `superpowers/specs/` | 已完成或已取代的规格、验证手册、审查清单。 | 查历史设计意图；当前行为以 README 和代码为准。 |
| `superpowers/plans/` | 已完成或已取代的实施计划、handoff、任务拆解。 | 查阶段任务来源；不要直接照旧任务框执行。 |
| `superpowers/reviews/` | 历史发布审查、阶段审核、整改结果、实验审计材料。 | 查证旧 finding 和整改证据；较新的当前审核优先。 |
| `reviews/` | 早期散落在 `docs/reviews/` 的专项审核。 | 只作历史参考。 |
| `issues/` | 已结案的问题排查记录（原 `docs/issues/`）。 | 只作历史参考。 |
| `plans/` | 早期散落在 `docs/plans/` 的专项计划。 | 只作历史参考。 |
| `reports/` | 根目录旧报告和迁移报告。 | 只作历史背景。 |

## 读取规则

- 当前操作、启动、架构和待办优先看根 README 的“长期维护文档”表。
- 带日期的归档计划和审核可能描述的是当时状态，不能直接覆盖当前代码事实。
- 如果归档文档重新成为当前依据，应移回对应 active 目录或在长期维护文档中明确引用。
